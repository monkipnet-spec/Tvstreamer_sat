# TVStreamer v86 — FTA auto-bypass

- Результат сканирования сервиса `scrambled` сохраняется как `satellite_scrambled`.
- FTA-сервисы автоматически создаются без `ca_provider_id`.
- Проверка CA reader и лимита сессий выполняется только для реально зашифрованных сервисов.
- Старое назначение CA на FTA больше не блокирует запуск: CA автоматически bypass.
- В плитке и редакторе FTA явно помечается как `FTA / CA не требуется`.
- Для старых конфигов без нового поля сохранена совместимость: наличие старого `ca_provider_id` считается признаком CA до повторного сканирования.
- Статус `no input signal` для FTA теперь явно сообщает, что CA не участвует; это отделяет RF/TS проблему от условного доступа.
