# TVStreamer5 v79 — ввод спутниковой частоты в MHz

## Что изменено

- В мастере **Добавить канал со спутника** поле частоты переведено с kHz на **MHz**.
- Пример ввода: вместо `11531000` теперь вводится `11531`.
- Разрешён шаг `0.001 MHz`, поэтому при необходимости сохраняется точность до 1 kHz.
- Перед сканированием значение автоматически умножается на 1000 и дальше используется существующий внутренний формат kHz.
- Старые конфиги менять не требуется: `satellite_frequency` в JSON по-прежнему хранится в kHz.
- В плитках/описании спутникового входа частота теперь отображается в MHz.
- LNB LOF1/LOF2/SLOF намеренно оставлены в kHz, чтобы не менять существующий низкоуровневый DVB/GStreamer контракт.

## Conditional Access

В этой версии не добавляется извлечение, кеширование или раздача ECM/CW/ключей. Для единого логического CA-provider требуется отдельный авторизованный backend с известным API/протоколом. Текущая сборка сохраняет существующую совместимость и явно предупреждает, если выбран физический Phoenix/serial reader, который фактически не подключён к descrambling pipeline.
