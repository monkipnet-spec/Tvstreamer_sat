# TVStreamer v83 — serial-reader inventory для CA Providers

## Что изменено

- В `System → CA Providers` добавлена таблица обнаруженных устройств `/dev/serial/by-id/*`.
- Для каждого reader отображаются:
  - стабильный путь `by-id`;
  - текущий `/dev/ttyUSB*` или `/dev/ttyACM*`;
  - производитель;
  - модель;
  - серийный номер.
- Добавлен API `GET /api/serial-readers`.
- Метаданные vendor/model/serial запрашиваются через `udevadm`; сопоставление `by-id → ttyUSB/ttyACM` выполняется через реальный symlink.
- В окне CA Providers есть кнопка `Обновить` для повторного обнаружения reader'ов без перезапуска TVStreamer.
- Новые CA Provider получают понятные ID `ca-card-1`, `ca-card-2`, ... вместо случайных временных ID.
- ID существующего provider теперь можно переименовать; при сохранении TVStreamer автоматически обновляет `ca_provider_id` у каналов, которые ссылались на старый ID.
- В интерфейсе явно указано, что USB/udev идентифицирует физический serial-reader, а идентичность вставленной карты должен сообщать внешний авторизованный CA backend.

## Совместимость

Старые конфиги сохраняют работоспособность. Существующие provider ID не переименовываются автоматически. При необходимости их можно переименовать вручную в `System → CA Providers`; ссылки каналов будут мигрированы при сохранении.
